# 直式除法練習

[野生的葦達鴨](https://github.com/weiduck) 做的平板練習。給國小資源班學生（書寫困難）用**點選**學直式除法：不用手寫、不用拖曳，按大大的 0–9 數字鍵，一格一格把藍框填好。開啟後直接進入單題練習。

線上版：[weiduck.github.io/tablet-div](https://weiduck.github.io/tablet-div/)

姊妹作：[直式乘法練習](https://weiduck.github.io/tablet-mult/)（同樣的外觀與操作方式）。

直式寫法依循**康軒數學**的「厂」形直式除法：除數在左、被除數在「厂」下面、商寫在上面並**對齊位值**；每一位商依序做 **商 → 積 → 差 → 移下來**。

## 怎麼打開

不需要安裝或建置。

1. **線上**：用瀏覽器開 [weiduck.github.io/tablet-div](https://weiduck.github.io/tablet-div/)
2. **直接開檔**：用瀏覽器開啟本資料夾的 `index.html`
3. **本機靜態伺服器**（若瀏覽器擋 `file://` 字型／manifest）：在本資料夾執行

```bash
python3 -m http.server 8765
```

然後開 `http://localhost:8765/`。

### 加到 iPad 主畫面（像 App 一樣全螢幕）

1. 用 **Safari** 打開 [線上版](https://weiduck.github.io/tablet-div/)（不要用 `file://`）
2. 點分享按鈕 → **加入主畫面**
3. 名稱會是「直式除法」；加入後從主畫面圖示開啟
4. **直向、橫向都可以用**：直向時直式板在上、題目與數字鍵在下；橫向時左右並排（不會出現「請轉橫向」提示）
5. 以 standalone／全螢幕方式執行，頁面不會亂橡皮筋滾動；只有直式板／步驟區在內容過長時可內部捲動

數字鍵每顆 ≥ 56px；其他按鈕約 48–56px。

## 九個題型（L0–L8）

| 題型 | 類型 | 隨機約束（例） |
|------|------|----------------|
| L0 暖身 | 二、三位 ÷ 一位 | 除數 2–9；商沒有 0（如 84÷4、275÷6） |
| L1 | 四位 ÷ 一位 | 商 3 或 4 位；商和被除數都沒有 0（如 8492÷4） |
| L2 | 四位 ÷ 一位・有 0 | 商中間／末尾有 0，或被除數有 0（如 2453÷8=306…5、1006÷3=335…1、1080÷3=360） |
| L3 | 二位 ÷ 整十 | 除數 10、20…90，含整十÷整十（如 90÷20=4…10、92÷30=3…2） |
| L4 | 二位 ÷ 二位（估商） | 除數個位≠0；偶爾被除數比除數小、商 0（如 86÷21、95÷28、87÷25、26÷29=0…26） |
| L5 | 三位 ÷ 二位・商一位 | 含三位÷整十（如 215÷32、180÷30） |
| L6 | 三位 ÷ 二位・商二位 | 如 672÷21、500÷32 |
| L7 | 四位 ÷ 二位 | 商 2 或 3 位，商中間沒有 0（如 6820÷20、2150÷26） |
| L8 | 四位 ÷ 二位・商中間 0 | 如 1900÷18=105…10、1860÷18=103…6 |

上方另有 **整除／有餘數／都可以**（預設「都可以」）。某題型的某些數字不可能整除（例如 26÷29），產生器會改選同題型的其他數字，一定出得出符合設定的題目。

**↻** 與完成後的 **再練一次**：留在同一題型重新出題。

**驗算**（L4 起可開）：做完直式後接著填 **除數 × 商 = ?**，有餘數時再填 **積 + 餘數 = ?**，確認等於被除數。

## 每一位商的步驟

| 步驟 | 學生做的事 | 答錯時 |
|------|-----------|--------|
| 商（估商） | 這一位商幾 | 告訴學生「太大了」（積比部分被除數大）或「太小了」（差沒有比除數小） |
| 積 | 商 × 除數，從右往左一位一位寫 | 提醒從右往左、算 商×除數 |
| 差 | 相減，從右往左寫；差一定比除數小 | 提醒借位 |
| 移下來 | 把被除數的下一位移下來 | 紅圈標出要移的那一位 |

版面規則（康軒）：

- 商寫在**部分被除數最後一位**的上面；最高位不夠商時**不寫 0**（245÷8 的 3 寫在 4 上面）
- 中間或末尾不夠商：**商 0 佔位**；這時 0 × 除數 那一列**不寫、不減**，直接把下一位移下來（提示會說明）
- 相減剛好是 0、後面還要移下來時，0 不寫
- 最後一列就是**餘數**（完成時標示「餘數」），餘數一定比除數小

**給我一個提示** 可展開／收起：估商時教「把除數四捨五入看成整十」（21 看成 20、28 看成 30），再一步一步試、調大或調小。

## 畫面

| 區塊 | 行為 |
|------|------|
| 開啟 | 直接進入 L0 單題練習 |
| 直式板 | 「厂」形除號與減法橫線用 CSS 畫；上方標定位（千百十個）；格子大小依螢幕自動調整 |
| 格狀態 | 空＝虛線；目前＝黃底粗藍框；已填＝淡綠；按錯＝紅色閃一下；紅圈＝這一步要看的數字 |
| 步驟區 | 階段＋大題、0–9 數字鍵、對／錯回饋、可展開提示 |
| 完成 | 完整算式 `被除數 ÷ 除數 = 商 … 餘數`（整除時 `= 商`），開驗算時另顯示驗算式 |

## 檔案

- `index.html` — 結構、繁中文案、PWA／主畫面 meta
- `styles.css` — 粗獷／貼紙感樣式；直向／橫向響應式版面、鎖捲動、safe-area
- `div-core.js` — 純邏輯（UMD：瀏覽器 `window.DivCore`、Node `require`）：長除法、`checkLevel` 題型約束、`generate` 出題、`buildSteps` 步驟引擎、`buildCheckSteps` 驗算
- `app.js` — 只有介面：直式板繪製、數字鍵、回饋與提示、觸控鎖
- `manifest.webmanifest` — 主畫面名稱「直式除法」、orientation any、standalone
- `icon.svg` / `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` — 圖示（PNG 由 `node tools/make-icons.js` 產生，無相依套件）
- `test/generator.test.js` — 產生器與步驟引擎測試（純 Node）
- `package.json` — 只有 `npm test` 指令，沒有相依套件
- `README.md` — 本說明

## 明確不做

- 手寫辨識、拖曳
- 登入／後端／雲端進度
- 分析、追蹤、在瀏覽器存學生資料（不用 localStorage）
- 建置工具（Webpack、Vite 等）
- 除了 Google Fonts 字型以外的網路連線
